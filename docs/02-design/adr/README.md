# ADR

설계 결정을 기록한다. **에이전트가 일반적인 모범 사례대로 짜면 틀리는 자리**가 우선이다.
여기 적힌 결정은 이미 대안을 비교해 고른 것이다. 기각된 대안을 다시 제안하지 않는다 —
바꾸려면 새 ADR 로 이 결정을 대체한다.

## 상태

- `채택` — 코드와 테스트가 이 결정을 따른다
- `제안` — 아직 정하지 않았다. **이 ADR 에 걸린 요구사항은 구현을 시작하기 전에 사람과 결정한다**
- `대체됨` — 새 ADR 이 이 결정을 바꿨다. 지우지 않는다

## 맥락      무엇이 문제였나
## 결정      무엇을 골랐나
